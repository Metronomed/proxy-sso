# Security

## Reporting a vulnerability

Report privately through [GitHub private vulnerability reporting](https://github.com/Metronomed/proxy-sso/security/advisories/new), not a public issue. Include what you found, how to reproduce it, and the tag you used. This is a one-person spare-time project; expect a reply within a week.

## Supported versions

Only the latest release gets fixes. Apps pin a tag, so move to the newest tag to pick one up.

## Scope

In scope: accepting a JWT that should be rejected, or account rules that sign one person in as another or let a link be captured or moved.

Out of scope: misconfigured proxy policies, and the first-link limitation in the README.
